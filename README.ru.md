# Loot Magnet для Borderlands 4

[English README](README.md)

Loot Magnet притягивает выпавшие предметы к персонажу и умеет подбирать экипировку в рюкзак. Два режима настраиваются отдельно: **магнит для лута** сохраняет предметы, а **магнит для мусора** подбирает и продаёт подходящую экипировку по нажатию своей клавиши.

**Версия 0.2.0 — экспериментальная сборка для Windows x64.** Она работает с исходным SDK и собственным нативным помощником в составе мода. Заменять DLL SDK не требуется.

## Возможности

- Независимые радиус, типы экипировки и редкости для каждого магнита.
- Подбор подходящей экипировки; притягивание патронов, денег, здоровья и эридия для штатного подбора при контакте.
- Pick up all gear подбирает экипировку независимо от галочек типов и редкостей, без продажи.
- Магнит для мусора продаёт только предметы, которые удалось однозначно связать с его собственным подбором по бинду. Ручной подбор продажу не запускает.
- Окно настроек и отдельное окно статистики: последний запуск, общий итог, число использований, подтверждённый подбор по типам и редкостям. Сброс с подтверждением.
- Сохранение настроек и статистики между запусками.

## Требования

- Borderlands 4, Windows x64.
- Python SDK для BL4 с `mods_base`. Эта сборка рассчитана на Python 3.14 и unrealsdk 3.2.0, коммит `b1852aa4`. Другие версии SDK нативным помощником не поддерживаются.
- [BLImGui](https://github.com/juso40/blimgui) для окон настроек и статистики.

Проекты SDK: [unrealsdk](https://github.com/bl-sdk/unrealsdk), [pyunrealsdk](https://github.com/bl-sdk/pyunrealsdk). Сначала установите SDK и BLImGui по инструкциям их авторов.

## Установка

1. Полностью закройте игру.
2. Скачайте [loot_magnet-0.2.0-native.zip](dist/loot_magnet-0.2.0-native.zip), нажав **Download raw file** на странице файла GitHub.
3. Уберите старую версию Loot Magnet из `sdk_mods` за пределы этой папки. Сохраните `sdk_mods/settings/loot_magnet.json`, чтобы не потерять настройки и статистику.
4. Распакуйте **папку `loot_magnet` целиком** из архива в `<Borderlands 4>/sdk_mods/`.
5. Запустите игру и включите Loot Magnet и BLImGui в меню модов SDK.

Правильная структура:

```text
Borderlands 4/
  sdk_mods/
    loot_magnet/
      __init__.py
      native/
        loot_native_bridge.dll
        build-manifest.json
```

Не переименовывайте ZIP в `.sdkmod`: нативная DLL должна быть распакована на диск. Устанавливайте только одну копию мода. На время проверки отключите другие магниты и моды автоматической продажи.

## Управление

| Клавиша по умолчанию | Действие |
| --- | --- |
| F6 | Магнит для лута: подобрать и оставить подходящие вещи |
| F8 | Магнит для мусора: подобрать и продать подходящую экипировку |
| F7 или Ctrl+F6 | Открыть настройки |

Основные действия можно переназначить в меню биндов SDK. Если настройки не открываются клавишей, выполните `lootmagnet_gui` в SDK-консоли. Статистика открывается из настроек или командой `lootmagnet_stats`.

Другие команды: `lootmagnet_preview`, `lootmagnet_run`, `lootmagnet_pickup_all`. Команды консоли и кнопки окна не разрешают продажу.

## Как работает магнит для мусора

По умолчанию мусорный фильтр принимает Common и Uncommon. Проверьте его настройки перед нажатием F8. Для продажи нужен загруженный торговый автомат; без него действие останавливается до подбора. Продажа вдали от автомата не проверена.

Продажа разрешается только при появлении ровно одного нового ID в рюкзаке сразу после конкретного запроса подбора. Старые вещи рюкзака, экипированные, заблокированные и вещи с ненулевыми флагами состояния исключены. Неоднозначный или отложенный подбор остаётся в рюкзаке; фоновой повторной продажи нет. Расходники и неизвестная редкость мусорным магнитом пропускаются.

## Ограничения и проверки

- Одиночный нативный подбор подтверждён в игре на исходной паре DLL SDK. Полный сценарий F6/F8 с пакетным подбором на этом SDK ещё требует игрового теста. Локальные mock- и ABI-тесты не эмулируют движок.
- Подбор читает поле по смещению, зависящему от сборки игры. Обновление игры может нарушить совместимость даже без изменения размера класса. Известные несовпадения SDK и сигнатуры помощник отклоняет.
- За запуск обрабатывается максимум 100 ближайших подходящих объектов. Нужно место в рюкзаке; свободные активные слоты оружия для подбора в рюкзак не требуются.
- Лишние патроны не удаляются. Расходники перемещаются для штатного контактного подбора, а не добавляются напрямую в инвентарь.
- Экипировка неизвестной редкости только перемещается при включении всех редкостей; Pick up all gear может попытаться подобрать её без продажи.
- Кооператив не проверен. Счётчики двух магнитов общие; истории отдельных предметов пока нет.
- Получение полных кодов предметов и фильтры по отдельным деталям ещё исследуются и в эту версию не входят.
